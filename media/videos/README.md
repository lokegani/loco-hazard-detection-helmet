## Demo Videos

Your demo videos are large (27 MB and 65 MB). GitHub allows files up to 100 MB, but it's not built for hosting video — repos get slow to clone and there's no player/streaming.

**Recommended:** Upload the videos to YouTube (unlisted is fine) or Google Drive, then link them here and in the main README, e.g.:

```markdown
## Demo Video
[Watch the prototype demo](https://youtu.be/your-video-id)
```

If you still want them in the repo directly, you'll need [Git LFS](https://git-lfs.com) (see the step-by-step guide) — plain `git add` on files this size will make the repo heavy and slow for anyone who clones it.
